🔑 Генератор уникальных ID

Создать ID

Дата не вводится — фиксируется автоматически в момент генерации и сохраняется во внутренней базе (при проверке восстанавливается по коду). ID детерминирован: одинаковые данные → одинаковый код. Читаемая часть: ER — Ericsson, 2HF — 2-я неделя августа, пятница, MS — Масштаб-Связь, A — порт TN_A, площадка. Повторное сохранение вернёт существующий ID.

Проверить ID

Проверка контрольного кода работает даже без доступа к базе (как CRC у серийных номеров).
