Создать ID

Дата не вводится — фиксируется автоматически в момент генерации и сохраняется во внутренней базе (при проверке восстанавливается по коду). ID детерминирован: одинаковые данные → одинаковый код. Читаемая часть: первые 2 символа — код производителя из справочника, далее 3 символа — дата (месяц B=Январь…Q=Декабрь, день A=Пн…G=Вс), 2 символа — код компании из справочника, буква — порт TN_A/TN_B/TN_C, следующие 4 символа — номер площадки. Повторное сохранение вернёт существующий ID.

Справочники кодов

JSON-конфиги создаются программой автоматически при первом запуске (или командой python cli.py codes-init) и хранятся в папке config/. При генерации ID готовые коды подставляются в код; если имени нет в справочнике — программа сообщит об ошибке.

База выданных ID

«Редактировать» — меняйте поля прямо в строке; после «Сохранить» UID будет пересчитан автоматически по новым данным (справочники и формат проверяются). «Удалить» убирает запись из базы без возможности восстановления.

Проверить ID

Проверка контрольного кода работает даже без доступа к базе (как CRC у серийных номеров). Если код корректен и есть во внутренней базе — показывается карточка изделия.
