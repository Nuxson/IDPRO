# 🔑 Unique ID Generator

Веб-приложение для генерации **уникальных идентификационных кодов** из пяти полей
(по принципу серийного номера / MAC-адреса) с внутренней базой данных и проверкой подлинности.

## Поля ввода
1. Производитель
2. Дата
3. Место положения
4. Компания
5. Серийный номер

## Формат ID
```
XXXX-XXXX-XXXX-CCKK      пример: RQTE-MQ9Q-HSEW-FG
│    │    │    └─ контрольный код (аналог CRC, 2 символа)
│    │    └────── префикс места + хеш-часть
│    └─────────── префикс компании + хеш-часть
└──────────────── префикс производителя
```
* Алфавит `base31` без неоднозначных символов (`0/O`, `1/I/L`) — как в реальных серийных номерах.
* Хеш-часть = SHA-256 от канонической строки `v1|производитель|дата|место|компания|серийный`.
* Контрольный код = HMAC-SHA256 от тела ID (секрет задаётся переменной окружения `IDGEN_SECRET`).
* ID **детерминирован**: одинаковые данные → одинаковый код; изменение любого поля → другой код.

## Как проверить подлинность
1. **Офлайн** — сверить контрольный код (защита от опечаток, работает без доступа к базе).
2. **По базе** — найти код во внутренней SQLite-базе и восстановить исходные поля.

## Запуск веб-интерфейса
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
# открыть http://localhost:8000   (Swagger: /docs)
```

## CLI
```bash
python cli.py generate --producer "Роботех" --date 15.03.2026 \
    --location "Москва" --company "Технопарк" --serial SN-00123
python cli.py preview  --producer "Эверест" --date 2026-09-28 \
    --location "Сочи" --company "Мортех" --serial MT-777
python cli.py verify RQTE-MQ9Q-HSEW-FG
```

## API
| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/generate` | Сгенерировать ID и сохранить в базу |
| POST | `/api/preview` | Показать ID без сохранения |
| GET  | `/api/verify?id=...` | Проверка: CRC + поиск в базе + подлинность |
| GET  | `/api/list` | Последние выданные ID |

## Структура
```
app/idgen.py           # ядро: нормализация, хеш, base31, контрольный код, разбор ID
app/db.py              # SQLite-база выданных кодов (ids.db)
app/main.py            # FastAPI REST + статика
app/static/index.html  # веб-интерфейс (создать / проверить)
cli.py                 # командная строка
tests/test_idgen.py    # тесты (pytest)
```

## Требования
* Python 3.9+
* Зависимости — в `requirements.txt` (`fastapi`, `uvicorn`, `pytest` для тестов).

## JavaScript-часть UI (`app/static/js/`)

Интерфейс разбит на отдельные JS-модули (index.html подключает их тегами `<script src=...>`):

| Файл | Назначение |
|---|---|
| `js/idgen.js` | Полный JS-порт алгоритма из `idgen.py`: `IdGen.makeId(fields)` → Promise с ID, `IdGen.verifyChecksum(id)` — офлайн-проверка контрольного кода прямо в браузере. Работает и в Node.js (`require`). Совпадение с Python верифицировано кросс-тестами. |
| `js/app.js` | Логика страницы: обработка форм «Создать ID» / «Проверить ID», запросы к REST API, отображение результатов и списка записей. |

Особенности:
- **Два режима**: с сервером (полная проверка по внутренней базе) и **офлайн** — если сервер недоступен, ID генерируется и проверяется локально в браузере через `idgen.js` (без записи в базу);
- SHA-256/HMAC через WebCrypto, с фолбэком на чистый JS там, где WebCrypto недоступен;
- Арифметика на BigInt — точная, как Python `int`, поэтому коды совпадают побайтно.

Запуск для разработки без бэкенда: достаточно открыть `app/static/index.html` — работает офлайн-генерация и офлайн-проверка кода.

## Переменные окружения
| Переменная | Назначение | По умолчанию |
|---|---|---|
| `IDGEN_SECRET` | секрет HMAC для контрольного кода (CCKK) — передаётся в `checksum()/make_id()/verify_checksum()` как параметр `secret` | если не задан — открытая SHA-256 контрольная сумма (в бою задайте свой секрет!) |

Путь к SQLite-базе выданных кодов: `ids.db` в корне проекта (параметр `db_path` во всех функциях `app/db.py`).
